A program that writes the one sentence a house cat would say in its own defence after knocking a glass off the table (under 200 characters) to `/output/entry.txt`, for make.fun's "Five Seconds to Explain the Glass" bounty. The line was critique-picked from 15 candidates against the judge's criteria — see [CANDIDATES.md](CANDIDATES.md) — and the winner reframes the glass as an informant the cat had to silence before it talked about the treats.

> It saw too much, it knew where the treats were hidden, and it had to go before it talked.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
